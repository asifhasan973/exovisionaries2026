# Earth texture provenance

`earth-blue-marble.jpg` is the unmodified 2048×1024 Blue Marble land/ocean/ice/cloud texture, locally included for the game's 3D Earth. It is not a live Earth observation.

Source: https://eoimages.gsfc.nasa.gov/images/imagerecords/57000/57735/land_ocean_ice_cloud_2048.jpg

Source catalogue: https://visibleearth.nasa.gov/view.php?id=57735

NASA description and availability: https://science.nasa.gov/earth/earth-observatory/the-blue-marble-true-color-global-imagery-at-1km-resolution/

Credit: NASA Earth Observatory / NASA Goddard Space Flight Center. Image by Reto Stöckli; ocean color, compositing and globe enhancements by Robert Simmon. MODIS land, atmosphere and ocean groups and other data providers are credited on the NASA page. The game displays credit in Flight notes.
