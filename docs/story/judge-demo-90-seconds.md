# 90-second judge walkthrough

0–12 s — “This is a mission-design game with two scientific objectives. I’ll use the labelled judge preview to fit the tour into ninety seconds; it preserves the main mission separately.”

12–28 s — Choose Ice Explorer or Geology Explorer. Show the instrument, battery and solar choices. “Mass, power and budget checks use this equipment. A larger battery stores more Wh; panels generate W. These numbers are authored teaching values.”

28–40 s — Show the route choice and a landing view. “Transfer time trades against fuel and supplies. Landing has player controls and safe touchdown limits.” Use labelled Skip for time where needed.

40–60 s — Show the rover and instrument readings. “The astronauts operate this rover from inside the lander. Collection and analysis use the installed instruments. Samples must be delivered. Hydrogen is a clue; Ice needs corroborating optical/gas readings. Geology needs complementary mineral or element evidence.”

60–72 s — Show docking or Earth return. “We separately account for ascent and service maneuvers. Crew recovery is earned at splashdown.” Use the assisted tour to reach the end if necessary.

72–90 s — Open the engineering report. Point to actual findings, two returned samples if the displayed run collected them, and the resource figures. “The debrief explains this run and gives three next-attempt suggestions. Save it here, play another configuration and compare recorded results. A different seed or assistance can also change results. This is an educational simulation, not NASA flight certification.”

Before presenting: use a tested completed run; never promise confirmed water, a particular classification or two samples unless the displayed record supports it. Be explicit whenever Skip/assistance is used.
