# Zero To Beyond — a short, truthful Judge walkthrough

**Premise:** Design a crew-and-rover Moon mission. Equipment changes what the mission can do. Earn science by using tools and interpreting their evidence; recover the crew before the final outcome.

## Show a design consequence first

Home → Judge demo → Start here → Battery challenge.

The assisted preparation reaches a real failed shadow rehearsal: 100 Wh cannot cover the chosen 100-cm drill plan and return reserve. Choose Fix, replace with Medium (220 Wh), then Retest mission. Revalidate cabin and mass, and perform Drive → Drill → Return. In the reviewed kit this changes a failure to 138 Wh remaining; the thresholds and consumption come from the same calculation in both runs.

Alternatively, choose Drill less. That is a different engineering solution, not a scripted correct answer. Rechecks recalculate the complete current kit.

## Show learning and mission completion

Exit demo → Judge demo → Science → Ice science or Rock science. These shortcuts assist previous chapters; they do not invent observations. Pick a site and measurements, watch resource use, answer from the instrument cards and transmit the evidence. A hydrogen clue alone does not confirm water. Rock classification needs matching analytical clues. An incident can interrupt the plan; protect the return reserve and crew.

For the final chapter: Exit demo → Judge demo → Return → Ice crew return or Rock crew return. These are explicitly assisted surface expeditions executed through the real reducers. The player still performs ascent, docking, Earth departure, heat-shield orientation and parachute deployment. Science points reflect delivered measurements; a bought tool's potential is not an earned score. Rover/descent hardware stay on the Moon; sealed Geology samples return only if collected and stowed. Crew recovery appears only after splashdown.

Save the mission card and JSON log. They disclose assistance, actual evidence, resources, source links and model assumptions.

## Say this honestly

NASA references inform instrument capabilities and the mission sequence. Our numeric balancing, terrain, readings and incidents are authored teaching models. This game does not query live lunar datasets, certify a flight plan, or make a real discovery. Animated characters use illustrated talking frames; they are not phoneme-accurate lip sync.
